# Enkore: The Millennium Race — Vision

> Status: **v0.2 — deliberately minimal.** Cut back to the core on 2026-08-02.
> Detail gets added to an iteration only when we actually reach it. Anything
> written down before that is guesswork, and guesswork ages badly.

---

## The pitch

**A fun combat racer.**

---

## What that means

- **You drive, you race, you wreck things.** Racing and destruction are the same
  activity, not separate modes.
- **One arena.** The whole game lives in a single place — The Millennium
  Tournament. One environment made well beats many made badly.
- **A field of AI rivals** to race and fight.
- **Fun is the only success metric.** If a build isn't fun to replay, nothing
  else about it matters.

---

## How we build it

**Iterations.** Each one adds a layer of fun on top of a game that already
works and is already playable. An iteration doesn't start until the previous
one is actually fun.

| # | Iteration | Status |
|---|---|---|
| 1 | **Feel + Race** — driving that feels good, laps, rivals, standings | ✅ Done |
| 2 | **Weight & Carnage** — damage and destruction | Next. Specifics undecided. |
| 3 | **Progression** — things that build up and carry forward | Later. Specifics undecided. |
| 4 | **Cast & Tournament** — the content pass: racer models, vehicles, the tournament holder | Later. Mostly asset work. |

Iterations 2 and 3 are named, not designed. They stay one line each until we
get there — see [BACKLOG.md](BACKLOG.md) for the structural work that has to
happen regardless.

---

## Principles

Short list. These are the ones that actually change decisions.

1. **Destruction is an objective, not decoration.** If wrecking things is only a
   side effect of racing, we've built the wrong game.
2. **Never gate the fun.** The best moments should be available in minute one.
3. **Easy to pick up.** Low friction to the first good moment.
4. **Upgrades change how you play, not just numbers.** (Applies from iteration 3.)
5. **Scope the spectacle so it runs flawlessly.** A smaller effect that never
   stutters beats a grand one that chokes.

## Deliberately undecided

Open questions. Not problems — just not answered yet, and not worth guessing at.

- **Art direction / visual identity.** Wide open. (Not neon.)
- **The specifics of iterations 2 and 3.**
- **Cast size** — how many racers and vehicles the game ships with.
- **The tournament holder** — the figure who runs the tournament. Needs an
  original identity.
